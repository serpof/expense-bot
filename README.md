# expense-bot

Семейный учёт расходов через Telegram. Траты наличными пишутся в чат, карточные приходят из банковской выписки, всё складывается в одну Google Таблицу, а отчёт за месяц бот присылает командой `/month`.

## Как пользоваться

**Наличные.** Пиши траты в чат с ботом, по одной в строке:

```
450 кофе
1 200 продукты
20 евро такси
12,5 € сувениры
```

Бот записывает строку в таблицу и ставит 👍. Сумма может стоять до слов или после, валюта по умолчанию — динары. Если суммы нет или чисел несколько («2 кофе 450»), бот переспросит.

**Категории.** Знакомые слова бот берёт из словаря. Новое слово определяет Claude и запоминает, а бот отвечает ««шаурма» → Кафе» с кнопками: если категория неверная, нажми нужную, и словарь поправится.

**Опечатки.** Исправь сообщение в Telegram, и строка в таблице поправится. Удалённые сообщения бот не видит: такую строку удали в таблице руками.

**Карта.** Карточные траты в чат не пиши. В конце месяца отправь боту выписку из банка файлом: PDF, XLSX или CSV. Бот:

- добавит покупки, оплату счетов и комиссии с пометкой «карта»;
- пропустит снятие наличных: эти деньги посчитаются, когда наличные потратят и запишут в чат;
- пропустит переводы между своими счетами и поступления;
- запишет возвраты минусом в ту же категорию;
- не создаст дублей, если загрузить ту же выписку ещё раз;
- предупредит, если трата на ту же сумму в тот же день уже есть в чате наличными.

**Отчёт.** `/month` — текущий месяц, `/month 10` или `/month 2026-10` — другой, `/month прошлый` — прошлый. В отчёте итог, сравнение с прошлым месяцем и разбивка по категориям.

## Таблица

- **Первый лист** — траты: Дата | Сумма | Валюта | Категория | Комментарий | Автор | ID сообщения | Сумма RSD | Источник. Недостающие колонки бот добавит сам при запуске.
- **Категории** — список категорий с подсказками для Claude. Переименовывать, добавлять и удалять можно прямо в таблице.
- **Словарь** — «слово → категория». Бот пополняет его сам, править можно руками.

Изменения во вкладках бот подхватывает в течение 5 минут. Для графиков подойдёт сводная таблица: Вставка → Сводная таблица, строки — Категория, значения — Сумма RSD.

## Настройка

Нужен Python 3.13: под 3.15 пока нет сборок части библиотек.

### 1. Секреты

Всё секретное лежит в папке `secrets/`, она в `.gitignore`.

| Файл | Что внутри |
|---|---|
| `bot_token.txt` | токен бота от @BotFather |
| `service_account.json` | ключ сервисного аккаунта Google |
| `anthropic_key.txt` | ключ Claude API |
| `allowed_chats.txt` | ID чатов, где бот работает, по одному в строке |

Ключ Claude API создаётся в Claude Console на странице API keys: [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys). При создании выбери workspace, например Default. На балансе аккаунта должны быть деньги.

```bash
pbpaste > secrets/anthropic_key.txt   # записать ключ из буфера обмена в файл: так он не попадёт в историю команд
```

Без ключа бот тоже работает, но новые слова уходят в «Прочие» (категорию выбираешь кнопкой), а выписки не разбираются.

### 2. Запуск на Mac

```bash
cd ~/expense-bot && source .venv/bin/activate   # перейти в проект и включить окружение
pip install -r requirements.txt                 # поставить библиотеки по списку
python -m expense_bot.bot                       # запустить бота; остановить — Ctrl+C
```

Бот приватный: в чужих чатах он только присылает ID чата. Напиши ему `/start`, допиши ID в разрешённые и перезапусти бота:

```bash
echo "123456789" >> secrets/allowed_chats.txt   # дописать ID чата в конец файла; >> не затирает старые строки
```

### 3. Семейный чат

1. Создай группу в Telegram и добавь в неё бота.
2. В @BotFather: `/setprivacy` → выбери бота → `Disable`. Иначе в группе бот видит только команды. После этого удали бота из группы и добавь снова.
3. Отправь в группе `/start` и допиши ID группы в `secrets/allowed_chats.txt`. У групп ID отрицательный, например `-1001234567890`.

### 4. Запуск по расписанию в GitHub Actions

Бот запускается каждые 15 минут с 7:00 до 23:00 зимой (летом с 8:00 до полуночи), забирает накопившиеся сообщения и выключается. Ночью сообщения ждут в Telegram: он хранит их 24 часа. Ответ приходит с задержкой до 15 минут.

```bash
gh secret set TELEGRAM_TOKEN < secrets/bot_token.txt                       # секрет репозитория из файла; значение не появится в терминале
gh secret set GOOGLE_SERVICE_ACCOUNT_JSON < secrets/service_account.json  # ключ Google
gh secret set ANTHROPIC_API_KEY < secrets/anthropic_key.txt               # ключ Claude API
gh secret set ALLOWED_CHAT_IDS < secrets/allowed_chats.txt                # разрешённые чаты
gh variable set BOT_SCHEDULE --body on                                    # включить расписание; off — выключить
gh workflow run bot.yml                                                   # запустить один раз прямо сейчас, не дожидаясь расписания
```

- Пока расписание включено, не запускай бота на Mac: два бота мешают друг другу забирать сообщения.
- В публичном репозитории GitHub отключает расписание, если 60 дней не было коммитов. Включить обратно: вкладка Actions → bot → Enable workflow.
- Логи Actions в публичном репозитории видны всем, поэтому бот пишет туда только служебные сообщения, без трат.

## Тесты

```bash
pytest -v   # прогнать все тесты; -v = каждый тест отдельной строкой
```

Тесты не ходят в сеть: Telegram, Google Таблица, Claude и курсы валют подменены заглушками из `tests/fakes.py`. На каждый push тесты запускаются в GitHub Actions.

## Стоимость

Telegram, Google Таблицы, курсы НБС и GitHub Actions для публичного репозитория бесплатны. Claude API (модель Claude Haiku 5.5) нужен для новых слов и выписок и стоит центы в месяц.

## Устройство

| Модуль | Что делает |
|---|---|
| `parser.py` | разбирает «450 кофе» на сумму, валюту и комментарий |
| `categories.py` | словарь и категории по умолчанию |
| `llm.py` | запросы к Claude: категории и разбор выписки |
| `rates.py` | курсы НБС для пересчёта в динары |
| `sheets.py` | чтение и запись Google Таблицы |
| `statement.py` | правила импорта выписки: что считать тратой, дубли |
| `reports.py` | отчёт `/month` |
| `service.py` | сценарии: записать трату, исправить, загрузить выписку |
| `handlers.py` | обработчики Telegram |
| `bot.py` | бот работает постоянно — для Mac |
| `run_once.py` | один проход по очереди сообщений — для GitHub Actions |
